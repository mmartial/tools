Misc Tools

-   [nc_wire](nc_wire/README.md)
    -   Copies a file to a remote server using Python TCP sockets (wire transfer) for speed.
        The script uses ssh for authentication and shell access to the destination.
- [apt-cache-ng](apt-cache-ng/README.md)
    -   Automatically uses the `apt-cacher-ng` proxy when on the local LAN, and falls back to `DIRECT` otherwise — no manual reconfiguration needed when moving between networks.
